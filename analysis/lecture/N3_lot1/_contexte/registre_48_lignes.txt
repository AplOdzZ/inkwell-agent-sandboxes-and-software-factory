Tenue du registre
Une ligne par écart, ajoutée dès qu'un fichier analysé contredit le code ou est périmé pour nous.
La colonne « Réalité » cite toujours sa preuve : fichier et ligne du code, ou la source vérifiée.
Quatre types : la doc d'Inkwell en retard sur son propre code ; un élément juste dans le dépôt mais périmé pour notre usage (modèles, prix, versions) ; une faille, quand le code laisse passer ce qu'il prétend empêcher ; un bug du code, qui le fait planter ou mal fonctionner.
Le statut passe à « Corrigé » quand notre version intègre la correction, ou à « Sans objet chez nous » si l'élément ne sera pas repris.
Avant l'intégration dans Pi (Phase 3), chaque ligne « À corriger » doit être traitée.
